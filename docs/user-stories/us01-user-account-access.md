# US01: User Account Access

## User Story

As a user, I want to register, log in, and log out so that I can access personal features in NewsLens.

## Priority

10

## Estimate

3 days

## Iteration

Iteration 1

## Tasks Completed

- Configured Django authentication routes.
- Created user registration view.
- Created login and registration templates.
- Added login, logout, and register navigation links.
- Tested registration, login, logout, and navigation manually.

## Evidence of Completion

The system allows users to create an account, log in, and log out. The navigation bar changes depending on whether the user is logged in or not.

## Testing Notes

Manual testing was completed by creating a new account, logging in, checking the authenticated navigation links, logging out, and confirming the public navigation appeared again.

## Final Status

Completed
