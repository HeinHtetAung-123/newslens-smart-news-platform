# US11: User Preferences

## User Story

As a logged-in user, I want to choose preferred categories so that NewsLens can recommend articles that match my interests.

## Priority

40

## Estimate

- Displayed recommended articles on homepage.

Logged-in users can open the preferences page, select categories, and see recommended articles on the homepage based on those selected categories.
