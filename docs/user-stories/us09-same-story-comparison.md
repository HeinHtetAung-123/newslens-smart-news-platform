# US09: Same-Story Comparison

## User Story

As a reader, I want to compare how different sources report related stories so that I can understand coverage from more than one perspective.

## Priority

30

## Estimate

5 days

## Iteration

Iteration 3

## Tasks Completed

- Added compare sources route.
- Created compare sources view.
- Created compare sources template.
- Displayed selected article.
- Displayed related source cards.
- Added visual source map.
- Added comparison insight guidance.

## Evidence of Completion

Users can open the Compare Sources page from an article detail page. The page shows the selected article, related coverage cards, and a visual source map that connects the selected article with related articles.

## Testing Notes

The compare page was tested by opening it from an article detail page and confirming that related articles from the same category appeared.
