# US05: Search News

## User Story

As a reader, I want to search for news articles so that I can find relevant stories quickly.

## Priority

20

## Estimate

3 days

## Iteration

Iteration 1

## Tasks Completed

- Added search form to the base layout.
- Created search URL route.
- Created search view.
- Created search results template.
- Added search matching for article title, description, summary, source, and category.
- Tested matching and non-matching searches.

## Evidence of Completion

Users can enter a search term and receive a list of matching articles. The search works across article content, source names, and category names.

## Testing Notes

Search was tested using article titles, source names, category names, and terms that should return no results.

## Final Status

Completed
